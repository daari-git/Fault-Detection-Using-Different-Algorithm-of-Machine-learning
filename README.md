Fault Detection using Machine Learning
This repository contains Python scripts for fault detection in transmission lines using machine learning techniques:
  1. SVM Classifier - Implements a Support Vector Machine (SVM) model for fault type classification.
  2. Decision Tree Classifier - Implements a Decision Tree model for fault type classification.

Model Evaluation<br>
Both models are evaluated based on:<br>
  1. Confusion Matrix<br>
  2. Classification Report (Accuracy, F1-score, Precision, Recall)
